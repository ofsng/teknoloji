# On the Arithmetic Properties of A Truncated Power-Residue Function and Related Diophantine Equations

## 1. Araştırmanın özeti

> We study the arithmetic function κ m ( n ), defined as the largest m -power-free divisor of n . We establish its fundamental properties and solve several Diophantine equations involving κ m ( n ) and Euler’s totient function ϕ ( n ). We prove that ϕ ( n ) = κ m ( n ) has exactly m + 1 solutions, characterize all solutions to ϕ ( n ) | κ m ( n ), and provide a complete parametric description of solutions to κ m ( n ) = d . Our results highlight the utility of the maximal divisor characterization in Diophantine analysis.
