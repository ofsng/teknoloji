# Generating scRNA-seq data from bulk RNA-seq using a Gaussian mixture variational autoencoder

## 1. Araştırmanın özeti

> Single-cell RNA sequencing (scRNA-seq) provides detailed, genome-wide gene expression profiles at single-cell resolution, enabling the identification of disease-driving cell types and genes. However, scRNA-seq remains costly, and there are extremely limited samples generated in even the most extensive human disease studies. In contrast, bulk RNA-seq data is abundant but averages gene expression across all cell types, losing cell-specific detail. To further leverage this abundance of RNA-seq data, methods have been developed to infer cell type proportions and average expression from bulk data using scRNA-seq as a reference. Additionally, generative AI models have been developed to generate more of an existing scRNA-seq dataset, spatial transcriptome data from bulk, and a complete single-cell dataset from bulk, with an incomplete set of single-cell data, for large cohort studies. However, there is a lack of tools specifically dedicated to generating representative single-cell RNA-seq from bulk RNA-seq data. To address this, we develop an innovative, modular framework, termed Bulk2SC, that takes full advantage of powerful generative AI approaches and existing scRNA-seq data to generate representative scRNA-seq data from bulk RNA-seq. Bulk2SC uses a Gaussian mixture variational autoencoder for data generation together with any tool that predicts cell type proportions from bulk RNA-seq data. We demonstrate the superior performance of Bulk2SC relative to tools that generate scRNA-seq from bulk RNA-seq as part of broader computational frameworks on published datasets from multiple tissue types. We also apply and assess Bulk2SC on a benchmark deconvolution dataset that contains paired bulk and single nucleus RNA-seq data. The modular design of Bulk2SC allows for deconvolution of single datasets as well as straightforward implementation within larger computational frameworks.
