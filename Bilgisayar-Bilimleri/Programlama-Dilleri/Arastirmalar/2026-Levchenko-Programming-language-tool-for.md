# Programming language as a tool for teaching algorithmization and programming within the framework of the subject "Informatics" in basic general education

## 1. Araştırmanın özeti

> Nowadays, it is crucial for specialists across almost all professional fields to be competent in programming as a core information technology. Therefore, teaching algorithmization and programming is mandatory at the basic school level, which is reflected in the regulatory documents governing informatics education. Despite extensive methodological experience in this area, informatics teachers still face the challenging problem of choosing a programming language from the official regulatory list for students' initial acquisition of algorithmic skills and programming techniques in basic school.Based on a survey of informatics teachers and an analysis of scientific and pedagogical publications, this study identifies not only the programming languages selected for basic school but also the rationale behind these choices.The article highlights the objectives of teaching algorithmization and programming and formulates requirements for a programming language as a tool for implementing the "Algorithms and Programming" thematic unit within the basic school "Informatics" curriculum. As a result of the analysis, the Pascal programming language is proposed as the primary and mandatory language for the initial acquisition of algorithmic skills and programming techniques. The school algorithmic language should be viewed as a method of algorithm notation that facilitates the transition from a flowchart to source code by representing the structural form of the algorithm with a certain degree of formalization in natural language. The remaining programming languages from the regulatory list (Python, C++, Java, C#) should be utilized selectively, considering their specific features and educational goals within elective modules or specialized courses in basic school
