# Model-Driven Engineering for Agent-Based Modeling: A Review

## 1. Araştırmanın özeti

> Agent-based modeling (ABM) is used to simulate complex adaptive systems. However, traditional development lifecycles often involve a semantic gap between domain conceptualization and manual coding, which results in unintentional simulation of artifacts and implementation errors. Model-driven engineering (MDE) addresses this by automating code generation. Following the Preferred Reporting Items for Systematic Reviews and Meta-Analyses (PRISMA) guidelines, this systematic literature review identified 1,059 records in six major databases up to November 12, 2025, retaining 60 primary studies. The results suggest a switch to domain-specific programming languages (DSLs). Despite MDE automation capabilities, the current state of the art faces three bottlenecks, which manifest as linguistic lock-in and associate technical complexity, behavioral reductionism that complicates the automated representation of dynamic execution semantics, and platform execution dependence. We synthesize these challenges into a roadmap and conclude that a transition to lightweight, decoupled, and agile MDE architectures could support agent-based modeling.
