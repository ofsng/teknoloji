# A Nonce-Bound Lightweight Mutual Authentication Protocol for UAV-Assisted Smart Mining Systems

## 1. Araştırmanın özeti

> Unmanned aerial vehicles (UAVs) support surveying, slope monitoring, inspection, and emergency observation in smart mines, but their wireless access links expose operational data and commands for impersonation, replay, modification, and tracking. This paper presents a lightweight mutual authentication protocol for a three-entity mining architecture consisting of a UAV, an edge gateway, and a mine control center. The protocol uses HMAC-SHA-256, fresh nonces, dynamic pseudonyms, and a dual-slot backend state. A server response is bound to the active gateway challenge, and per-UAV state lookup, replay checking, and updates are performed atomically. These rules reject delayed responses and serialize backend updates. A Real-or-Random analysis considers session-key secrecy under uncompromised endpoints and protected backhaul transport; final-response-loss recovery additionally assumes that backend requests are committed in attempt order. Transition-level tests cover normal completion, final-message loss and recovery, delayed response, replay, and authenticator modification. Performance analysis derives the proposed operation and communication costs and compares them with five published UAV authentication protocols. The proposed UAV performs one nonce generation and five HMAC evaluations; its authentication protocol payload is 1024 bits on the UAV-facing radio link and 2048 bits across all five link transmissions, excluding link/transport headers and protected-backhaul cryptographic overhead.
