# MedClassNet: a novel NLP framework for automated disease classification from clinical text using transformer and graph attention networks

## 1. Araştırmanın özeti

> Abstract A combination of complex vocabulary, acronyms, and relationships in clinical narratives makes automatic disease classification from clinical narratives challenging. The study proposes the MedClassNet framework that combines Graph Attention Network (GAT) and BioBERT-based contextual embeddings for disease classification in clinical narratives. The MedClassNet framework uses BioBERT embeddings of admission and progress notes and generates a similarity graph for patients by using the cosine similarity between patient contextual embeddings. To classify diseases, the BioBERT framework is combined with the relational embedding learned by the GAT framework for clinically similar patients. An annotated corpus of 1,748 clinical narratives from MIMIC-III dataset containing single-label ICD-9 disease categories is used for experimentation. To avoid label leakage, discharge summaries, final diagnosis, explicit ICD-9 codes, and other post-diagnosis data are excluded from the input for model training. According to the experimental protocol, MedClassNet framework yields an accuracy of 94.2%, a precision of 94.6%, and F1-score of 0.93. Clinically relevant textual features responsible for predictions of the model are discovered by using SHAP-based analysis. The results indicate that combining patient-level relational information with clinical language contextual embeddings can improve disease classification performance as compared with baseline models.
