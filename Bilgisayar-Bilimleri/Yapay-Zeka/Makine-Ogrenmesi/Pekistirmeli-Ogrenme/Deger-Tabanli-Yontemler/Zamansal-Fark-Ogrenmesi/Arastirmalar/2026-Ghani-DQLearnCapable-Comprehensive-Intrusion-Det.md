# DQLearnCapable: A Comprehensive Intrusion Detection and Prevention System for Network Traffic Analysis using Deep Q-Learning

## 1. Araştırmanın özeti

> As technology advances, the variety of cyber threats becomes more apparent in the networking world, presenting new and dynamic attack challenges to network users. Therefore, there is a need for artificial intelligence-assisted or self-governing threat detection systems capable of adaptive learning. In recent years, reinforcement learning methods and traditional machine learning (ML) techniques have been proposed for automated threat detection systems. A new generation of threat detection methods with adaptive learning abilities, combining Q-learning from reinforcement learning with deep neural networks is introduced. This study proposes a Deep Q-learning (DQL) model that learns through a subset of the environment iteratively using a trial-and-error approach to optimize its decision-making. The proposed DQL model is benchmarked against conventional ML and ensemble methods, including logistic regression, stochastic gradient descent, and random forest (RF), using standard performance metrics and execution time analysis. Based on extensive comparisons using the VHS-22 dataset, RF and extra tree classifier achieve noticeably higher detection performance than DQL in terms of classification metrics, while DQL demonstrates substantially lower inference latency and competitive overall effectiveness, although DQL still outperforms other similar ML approaches. Experimental results show that while ensemble models achieve higher detection accuracy, the DQL-based approach shows a competitive performance with significantly lower inference latency, making it more suitable for fast-streaming and time-sensitive intrusion detection scenarios. These findings also highlight the complementary role of reinforcement learning–based intrusion detection systems in environments where adaptability and real-time responsiveness are critical.
