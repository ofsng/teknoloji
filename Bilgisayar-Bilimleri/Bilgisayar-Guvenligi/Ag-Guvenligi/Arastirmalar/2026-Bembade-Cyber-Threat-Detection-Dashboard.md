# Cyber Threat Detection Dashboard a Centralized Platform for Network Security Monitoring and Threat Analysis

## 1. Araştırmanın özeti

> Cybersecurity threats such as malware, phishing, unauthorized access, Distributed Denial of Service (DDoS), and suspicious network activities are increasing rapidly with the growth of digital technologies and internet-based services [2], [7], [8]. These threats create significant challenges for organizations in maintaining the confidentiality, integrity, and availability of information [1], [2]. Security information is frequently distributed across multiple monitoring tools, system logs, firewall systems, and security applications, making it difficult for users to understand the overall security condition of a network. Examining different sources separately can increase the complexity of threat identification, security analysis, and incident management [2], [3]. To address these challenges, this paper proposes a Cyber Threat Detection Dashboard, a centralized web-based platform designed to monitor network activities, display potential cyber threats, classify security alerts, and provide a comprehensive overview of system security. The proposed system integrates network monitoring, threat alert management, security status monitoring, user activity analysis, graphical visualization, and incident response functionalities into a single interface. The dashboard displays important security information through statistical metrics, charts, tables, and recent event logs. It also provides response options such as isolating devices, blocking suspicious IP addresses, quarantining files, and generating incident reports. The proposed framework aims to improve security visibility, simplify monitoring activities, and support cybersecurity analysis through a user-friendly interface. The system is intended for academic cybersecurity projects, network security monitoring, and Security Operations Center demonstrations.
