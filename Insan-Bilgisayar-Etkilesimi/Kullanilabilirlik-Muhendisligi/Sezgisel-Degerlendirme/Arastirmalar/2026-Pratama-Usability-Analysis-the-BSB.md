# Usability Analysis of the BSB Mobile Application of Bank Sumsel Babel Using Heuristic Evaluation

## 1. Araştırmanın özeti

> Bank Sumsel Babel was established on November 6, 1957, as a regional government owned bank that provides banking services to various companies and government institutions. Currently, e mobile has become an essential means of supporting various fields, including business, education, government, e commerce, media, and many others. Through e mobile, information and services can be accessed globally, providing users worldwide with greater accessibility and facilitating broad communication. One of the commonly used methods for evaluating system usability is Heuristic Evaluation. Usability analysis of the Bank Sumsel Babel BSB Mobile application using the Heuristic Evaluation method is a process of assessing the extent to which the BSB Mobile system can be used effectively, efficiently, and satisfactorily by users. Therefore, an evaluation is necessary to assess and test the BSB Mobile system of Bank Sumsel Babel. In the study entitled "Usability Analysis of the Bank Sumsel Babel Website Using Heuristic Evaluation," a usability analysis was conducted on a website using the Heuristic Evaluation method. This method employs a set of heuristic principles or guidelines formulated by experts in the fields of human computer interaction and user interface design.
