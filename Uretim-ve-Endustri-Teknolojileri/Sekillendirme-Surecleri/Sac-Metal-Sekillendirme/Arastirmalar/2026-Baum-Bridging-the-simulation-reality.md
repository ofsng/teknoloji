# Bridging the simulation-to-reality gap in sheet metal forming via delta modeling

## 1. Araştırmanın özeti

> Shortening development cycles of formed sheet metal components requires bridging the gap between numerical sheet metal forming simulation and the actual manufacturing process. Springback effects currently cause substantial discrepancies between simulated predictions and physical outcomes, resulting in time-consuming manual tool tryouts. To address this simulation-to-reality gap, this paper proposes a Delta Model that corrects finite element simulation results using learned deviations from real measurement data. By training with the newly acquired ‘Real Deep Drawing and Cutting’ (RDDAC) dataset, which synchronizes experimental 3D point cloud measurements with corresponding simulations, this Delta Model significantly improves prediction accuracy. Furthermore, by capturing complex geometric deviations and weighting various influence factors, this data-driven approach facilitates automated and robust active surface design across component geometries.
